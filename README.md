# 三国·破阵录 — 军势指挥版 0.2

[在线试玩](https://acshan.github.io/sanguo-pozhen/) · [旧版个人动作原型](https://acshan.github.io/sanguo-pozhen/classic.html)

现在你指挥一支军势：随机招募武将、战前编排部队、战中暂停布令，通过三场战斗。每名武将带一队兵，兵力下降会减少可见人数和输出。

参考《三国志 BOND》公开介绍中的随机招募、布阵与自动战斗方向，加入本项目原创的战中命令、指挥点军略与阵旗规则。未使用 BOND 的代码、角色立绘或游戏素材。

参考入口：[官方网站](https://sangokushi-bond.com/zh-Hant)、[发行方 Steam 玩法说明](https://store.steampowered.com/app/4375230/BOND/?l=tchinese)。

## 玩法

1. 从三张随机武将中选一位，与初始的刘备、关羽、黄忠组成四队。
2. 查看敌方兵种和位置；点击武将部队卡，再点南侧 7×3 格部署，已有队伍会交换位置。盾和弓相邻可以形成协防。
3. 确认出阵，部队自动交锋。数字 1–6 选队，0 选全军；点空地指定行军目标。
4. A 推进、H 坚守、R 回撤；空格暂停战斗并继续布令。再按空格继续。切到后台自动暂停。
5. 火计：花 40 指挥点，点击战场指定范围。整军 35：恢复选中部队，全军选中时全军恢复。疾行 25：全军加速。军略共用三秒冷却，暂停时不会回复指挥点或冷却。
6. 无敌军争夺时，部队在中军旗范围内累计八秒，获得一次回复和指挥点。
7. 胜利后选择援军、整补或强化，重新布阵。三战全胜完成战役；全军覆没、营地失守或单场超时则失败。

骑兵克弓、弓克枪、枪克骑。敌军信息提前公开。武将有不同条件技能，悬停部队卡可查看。横阵/锋矢改变队内站位，当前不额外提高数值。

触屏可点击战场旁的快捷部队按钮选队，再点击地图下令；不用操作武将摇杆。

## 本地启动与检查

外层工作区根目录运行 `npm run sanguo`，或者本目录运行 `npm run dev`，打开 http://127.0.0.1:4190/ 。无需安装依赖，Three.js r186 已本地提供。

运行 `npm run check` 检查个人版的 12 项规则和军势版的 15 项规则，其中包含完整三场战役的固定种子模拟。默认每次重新演阵会生成新种子，不保证所有阵容自动推进都能赢。

## 当前限制

这是军势玩法原型，不是成熟 RTS。士兵显示在各自队伍阵型内；移动、伤害和目标选择按队伍计算，没有独立士兵寻路、复杂障碍碰撞或阵形挤压。三场使用同一灰盒战场、不同敌军编制。阵型、美术动画、平衡、远景识别和手机手感仍需迭代。

无多人、云存档、战役中途续玩、商业养成或 BOND 完整机制复刻。只把最高连破关数保存在当前浏览器；旧版最佳击破记录保留在独立存档键中。

测试包含规则模拟与浏览器交互，尚未做真实手机硬件、帧率基准或长时内存测量。浏览器记录见 browser-qa-v0.2.json。
